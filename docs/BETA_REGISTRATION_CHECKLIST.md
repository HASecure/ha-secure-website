# Checkliste Beta-Registrierung (von Denise zu liefern)

1. Airtable-Formularlink (privat, `https://airtable.com/...`) -> `REGISTRATION_URL` in `assets/registration.js`.
2. Verantwortlicher: Name/Organisation, Anschrift, Kontakt-E-Mail -> `privacy.html` (Platzhalter ersetzen).
3. Exakte Formularfelder/Datenarten, Speicherdauer/Löschfrist.
4. Bestätigung: Airtable-AVV, Transfermechanismus (Drittland), Zugriffskreis auf die Basis.
5. Rechtliche Prüfung des Datenschutztexts (Entwurf, keine Rechtsberatung).
6. Freigabe zum Merge; danach Pages-Build und Linkcheck der veröffentlichten Seite.

Solange `REGISTRATION_URL` leer ist, bleiben Button und Kontrollkästchen deaktiviert und es werden keine Daten erhoben.
