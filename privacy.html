Diese statische Website bindet standardmäßig keine Analyse- oder Werbeskripte ein und setzt selbst keine Tracking-Cookies.

Hosting

Die Website soll über GitHub Pages bereitgestellt werden. Beim Aufruf verarbeitet der Hosting-Anbieter technische Verbindungsdaten nach seinen eigenen Datenschutz- und Nutzungsbedingungen.

Feedback und Beta-Bewerbungen

Allgemeines Feedback über GitHub Issues ist öffentlich; GitHub-Benutzername und Beitrag sind sichtbar. Beta-Bewerbungen werden davon getrennt in einer privaten Airtable-Basis verwaltet. Kontaktdaten werden nicht in Git, öffentlichen Issues oder öffentlichen Tabellen veröffentlicht. Das Bewerbungsformular ist noch nicht geöffnet; es wird erst verlinkt, wenn ein privater Formularzugang eingerichtet und geprüft ist.

Reichweitenmessung

Es ist kein Google Analytics oder vergleichbarer Tracker eingebunden. GitHub stellt begrenzte Repository-Traffic-Statistiken für den jeweils letzten 14-Tage-Zeitraum bereit. Eine optionale Suchmaschinen-Verifizierung kann später eingerichtet werden.

Dies ist ein technischer Datenschutzhinweis und keine Rechtsberatung. Vor öffentlichem Betrieb sollte der Text mit Hosting-Einstellungen, möglicher Domain und den anwendbaren rechtlichen Anforderungen abgeglichen werden.
