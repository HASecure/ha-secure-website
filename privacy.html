Hosting

Die Website wird über GitHub Pages bereitgestellt. GitHub verarbeitet beim Aufruf technische Verbindungs- und Nutzungsdaten im Rahmen des Hostings. Maßgeblich sind ergänzend die Datenschutzhinweise von GitHub.

Keine Beta-Anmeldung

Das öffentliche Beta-Anmeldeformular ist derzeit geschlossen und auf dieser Website nicht eingebunden. Es werden über diese Seite aktuell keine Beta-Bewerbungen entgegengenommen und keine Bewerbungsdaten an Airtable übertragen. Die vorbereitete private Airtable-Warteliste enthält derzeit keine Einträge.

Vor einer späteren Aktivierung werden die konkreten Datenfelder, Zwecke, Kontaktangaben, Empfänger, Speicherfristen und etwaige Drittlandübermittlungen gesondert beschrieben. Ohne diese Angaben bleibt die Anmeldung geschlossen.

Feedback über GitHub

Das Feedbackformular führt zu GitHub Issues. Beiträge und GitHub-Benutzername sind dort öffentlich sichtbar und werden von GitHub verarbeitet. Bitte keine E-Mail-Adressen, privaten IP-Adressen, Hostnamen, Standortdaten, Zugangsdaten oder vertraulichen Home-Assistant-Konfigurationen in öffentliche Issues eintragen.
