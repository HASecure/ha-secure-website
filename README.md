# HA Secure – Portfolio

**Sichere, nachvollziehbare und modular erweiterbare Home-Assistant-Lösungen.**  
*Secure, transparent and modular Home Assistant solutions.*

HA Secure entwickelt eigenständige Home-Assistant-Erweiterungen für Sicherheit, Infrastruktur, Diagnose und Automatisierung. KI soll dort unterstützen, wo sie einen konkreten Mehrwert bietet – bleibt aber optional. Kernfunktionen, Sicherheitsregeln und Freigaben bleiben nachvollziehbar und deterministisch.

## Portfolio

Die Website stellt neun Projekte mit kurzen deutschen und englischen Beschreibungen, Produktpositionierung und transparentem Entwicklungsstatus vor. Geplante Funktionen sind ausdrücklich als geplant gekennzeichnet.

## Feedback

Rückmeldungen können über das öffentliche [GitHub-Feedbackformular](https://github.com/HASecure/ha-secure-website/issues/new?template=feedback.yml) eingereicht werden. Einreichungen sind öffentliche Issues; der GitHub-Benutzername und der Beitrag sind sichtbar. Das Formular fragt keine E-Mail-Adresse ab.

## Status

HA Secure befindet sich in aktiver Entwicklung. Beta-, experimentelle und Design-Reifegrade werden je Produkt separat ausgewiesen. Diese Website behauptet keine Produktionsfreigabe, wo sie nicht ausdrücklich angegeben ist.

## Hosting

Die Website ist als statische Seite für GitHub Pages vorbereitet. Es ist standardmäßig kein Google Analytics und kein eigener Werbe- oder Tracking-Code eingebunden.
